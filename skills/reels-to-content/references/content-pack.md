# Content pack structure

## 1. What works for @handle (short)
- 3–4 sentence summary: what they make, the 2–3 patterns behind their best reels.
- Small table: reels analysed · date range · reels/week · median views · median engagement · top pillar · top hook style.
- "Patterns to borrow" — 4–6 bullets, each: pattern → evidence (number) → how it applies to the user's niche.

## 2. Reel remakes (top 15 by views by default; the user's number if given)
Order by the source reel's views. For each:

**#N · Working title** — remakes [source reel](link) (views, engagement) · pillar · target length · format (talking head / screen record / B-roll + VO / text-on-screen / skit)

- **What we keep:** topic/promise, hook type, beat structure and format of the source, in one line.
- **Why it works:** one line tied to a finding (number).
- **Hook (0–3 s):** spoken line + on-screen text (in profile language). Give 2 alternatives.
- **Script beats:** 4–7 timed beats, e.g. `0–3s hook · 3–10s problem · 10–25s steps 1–3 · 25–30s payoff · 30–33s CTA`. Write the actual lines to say.
- **Visuals / shots:** what to film or show per beat; text overlays; transitions. Keep it filmable with a phone.
- **Caption:** first line as a second hook, 2–4 short lines, CTA. In profile language.
- **CTA:** one specific action (save, comment a keyword, follow for part 2, DM, link in bio).
- **Hashtags:** 3–6, mixing niche and broad; reuse tags that performed for the analysed account only if they fit the user's niche.
- **Audio note:** trending-audio slot or original voiceover (do not name copyrighted tracks to reproduce).

If several source reels belong to one series, keep them as a series for the user too.

## 3. Posting plan (2 weeks)
Table: day · reel # · posting time (based on the analysed account's best slots and the user's timezone; say if evidence is thin) · goal (reach / saves / followers / sales).

## 4. Notes
- How to measure: which metric to watch per reel after 48 h.
- Method & caveats: data source (Mindcase), reels analysed, date window, public data only.
